1. RDG 是什么

官方定义：RDG 是一套 immediate-mode API —— 按顺序调用 Create* / AddPass，命令被 记进一张图，再 Compile、再 Execute。它自动做易错操作，并遍历图来省显存、在 CPU/GPU 上并行 pass。

官方列出的能力一句话
Asynchronous compute fences按依赖在 Graphics / Async 队列之间插 fence
Transient resources + aliasing短命资源按寿命分配，不相交可共用显存
Split-barriers on sub-resources子资源 split-barrier，藏延迟、提高重叠
Parallel command list recording多线程录制 command list
Culling unused resources / passes丢掉图里没人用的资源和 pass
Validation检查用法和依赖
RDG Insights可视化图结构和显存寿命

Deferred / Mobile 以及相关插件都已切到 RDG。新的高层渲染应写 RDG，尤其要用到上表时。

图 1 · 官方核心：先记图，Execute 才跟 RHI 说话。写法像立即模式，执行是延迟的。

2. Shader Parameter Structs

RDG 的依赖，建立在 shader parameter struct 的扩展上。同一套槽位既给 HLSL 绑参数，也给 RDG 扫「谁读谁写」。

层长什么样
HLSLfloat2 ViewportSize; Texture2D SceneColorTexture; RWTexture2D<float4> SceneColorOutput;
理想 C++（不要手写）扁平 struct，里面是 FRHITexture* / FRHIUnorderedAccessView*
官方写法BEGIN_SHADER_PARAMETER_STRUCT + 一堆宏 → 结构体 + 编译期反射
BEGIN_SHADER_PARAMETER_STRUCT(FMyShaderParameters, /* MODULE_API */)
    SHADER_PARAMETER(FVector2D, ViewportSize)
    SHADER_PARAMETER(FVector4, Hello)
    SHADER_PARAMETER(float, World)
    SHADER_PARAMETER_ARRAY(FVector, FooBarArray, [16])
    SHADER_PARAMETER_TEXTURE(Texture2D, BlueNoiseTexture)
    SHADER_PARAMETER_SAMPLER(SamplerState, BlueNoiseSampler)
    SHADER_PARAMETER_TEXTURE(Texture2D, SceneColorTexture)
    SHADER_PARAMETER_UAV(RWTexture2D, SceneColorOutput)
END_SHADER_PARAMETER_STRUCT()

2.1 这些宏、变量、HLSL 类型是什么

每一行都是：宏（怎么往 C++ struct 里塞） + HLSL 类型（GPU 眼里它是什么） + 变量名（必须和 .usf 里同名）。

这一行宏在干什么变量是什么HLSL 侧
SHADER_PARAMETER(FVector2D, ViewportSize) 塞一个 常量（进 Constant Buffer） 视口宽高，例如 (1920, 1080) float2 ViewportSize
SHADER_PARAMETER(FVector4, Hello) 同上，四个 float 官方例子的占位名，随便什么四维数 float4 Hello
SHADER_PARAMETER(float, World) 单个标量 占位名，一个 float float World
SHADER_PARAMETER_ARRAY(FVector, FooBarArray, [16]) 常量数组，长度写在第三参 16 个 float3（C++ FVector 按 16 字节对齐常被当成 float4 槽） float3 FooBarArray[16]
SHADER_PARAMETER_TEXTURE(Texture2D, BlueNoiseTexture) 绑一张 只读 2D 贴图（RHI FRHITexture*） 蓝噪声贴图，用来破带、抖动 Texture2D BlueNoiseTexture
SHADER_PARAMETER_SAMPLER(SamplerState, BlueNoiseSampler) 绑一个 采样器（怎么读贴图） 和上一张贴图配对：滤波、寻址 SamplerState BlueNoiseSampler
SHADER_PARAMETER_TEXTURE(Texture2D, SceneColorTexture) 又一张只读 2D 图 场景颜色（上一 pass 画好的画面） Texture2D SceneColorTexture
SHADER_PARAMETER_UAV(RWTexture2D, SceneColorOutput) 绑一个 可写 视图（UAV） Compute 写出的目标图 RWTexture2D<float4> SceneColorOutput
HLSL / 宏里的类型是什么类比
Texture2D 一张 2D 像素数组，shader 里 只能读。Load(int2) 或 Sample(sampler, uv)。 一本只能翻的相册
SamplerState 不是图，是 读图的规则：线性还是点采样、UV 出界 Clamp 还是 Wrap、各向异性等。一张图可以配不同 sampler。 放大镜 / 滤镜，不是照片本身
RWTexture2D / RWTexture2D<float4> Read-Write Texture2D。Compute（或 UAV 光栅）可以 Output[xy] = color 直接写像素。一般要 UAV 绑定，不能同时当普通 Texture2D 采样（除非特殊）。<float4> 是每个像素四通道。 可以涂改的画板
FVector2D / float2 两个 float（宽、高或 UV） —
FVector4 / float4 四个 float（颜色 RGBA 或任意四元组） —
UAV Unordered Access View：GPU 上「随便写哪个像素」，不走光栅 RT 管线。CS 写图几乎都是 UAV。 和 SV_Target0 那条 RT 是另一条写路径
SRV Shader Resource View：只读绑到 shader。普通 Texture2D / StructuredBuffer 都是 SRV。 只读口

图 1b · 贴图是数据，Sampler 是读法，常量是数字，RW/UAV 才是 Compute 的写出口。光栅 PS 写颜色通常走 RT（SV_Target），不走 UAV。

SHADER_PARAMETER_TEXTURE + SAMPLER 是 旧 RHI 绑法（C++ 里是 FRHITexture*）。进 RDG 后同一意图改成 SHADER_PARAMETER_RDG_TEXTURE，RDG 才能看见依赖边。我们 Stamp 的 T_Combined 就是 RDG 版只读图；写 Dest 走的是 RENDER_TARGET_BINDING_SLOTS，不是 RWTexture2D。

宏对应 HLSLRDG 是否当资源边
SHADER_PARAMETER(Type, Name)常量 / 数组否
SHADER_PARAMETER_TEXTURETexture2D（RHI 指针）否（旧绑法）
SHADER_PARAMETER_UAVRWTexture2D否（旧绑法）
SHADER_PARAMETER_RDG_TEXTURE同上，但是 FRDGTexture*是
SHADER_PARAMETER_RDG_TEXTURE_UAVCS 可写是
SHADER_PARAMETER_RDG_BUFFER_SRVStructuredBuffer是

反射：FMyShaderParameters::FTypeInfo::GetStructMetadata()。每个成员有名字、C++/HLSL 类型、byte offset。RDG 靠扫这些成员 推 pass 依赖。详见 FShaderParametersMetadata::FMember。

3. Shader Bindings

参数 struct 要和 FShader 配在一起，才能往 command list 上绑。

步骤做什么
1派生 FGlobalShader（或 Material shader）
2DECLARE_GLOBAL_SHADER
3SHADER_USE_PARAMETER_STRUCT(本类, 基类) —— 生成构造函数，注册绑定
4using FParameters = FMyShaderParameters; 或在类里内联 BEGIN_SHADER_PARAMETER_STRUCT(FParameters,)
5填 struct，调用 SetShaderParameters(RHICmdList, Shader, ShaderRHI, Parameters)
class FMyShaderCS : public FGlobalShader
{
    DECLARE_GLOBAL_SHADER(FMyShaderCS);
    SHADER_USE_PARAMETER_STRUCT(FMyShaderCS, FGlobalShader);
    using FParameters = FMyShaderParameters;
};

不经过 RDG 时：SetComputeShader → 填栈上 FParameters → SetShaderParameters → DispatchComputeShader。RDG 只是把「填参数 + Dispatch」推迟进 pass lambda，并把 RHI 指针换成 RDG 句柄。

4. Uniform Buffers 与 Static Bindings

4.1 普通 Uniform Buffer

宏作用
BEGIN_UNIFORM_BUFFER_STRUCT / END_…声明一组打成一个 RHI UB 的参数
IMPLEMENT_UNIFORM_BUFFER_STRUCT(Type, "HLSL名")登记，并生成 HLSL（UniformBuffer.Member）
SHADER_PARAMETER_STRUCT_REF在父 FParameters 里引用这份 UB

HLSL 通过 /Engine/Generated/GeneratedUniformBuffers.ush（Common.ush 会带上）。每个 UB 是一个 全局命名空间。

4.1b 官方 sample / 我们 Stamp 为什么没用这套 UB 宏

上面三行宏是为了做一份 有名字、可复用、多 shader 共享 的 Buffer（如 SceneTexturesStruct）。官方 §2 那个 FMyShaderParameters，以及我们的 FRoadLandscapeProfilePS::FParameters，都 不必 再包一层。

SHADER_PARAMETER(float, World) 这种BEGIN_UNIFORM_BUFFER_STRUCT
干什么写在 这一个 shader 的 FParameters 里单独登记一份 全局命名空间，很多 shader 都能 UB.成员
常量存在哪引擎仍会打进一份 隐式 root Uniform Buffer（SetShaderParameters 自动建）你自己命名的那份 UB
谁用仅本 pass / 本 Global ShaderView、SceneTextures、整帧共用
HLSL直接写 float World;SceneTexturesStruct.SceneColorTexture
我们 Stamp 里的东西它是哪种 Buffer为什么不是 §4.1 那种 UB
NumSamples / StampSize / 矩阵隐式 CB（跟在 FParameters 后面）只有这一个 PS 用，不必 IMPLEMENT_UNIFORM_BUFFER_STRUCT
Samples（StructuredBuffer）Structured Buffer + SRV最多 4096 个 struct，UB 太小（常见几 KB 上限），而且是「很多条记录」不是「几个常量」
T_Combined贴图 SRV贴图不放进普通 UB
DestRender Target光栅写口，不是 UB

所以不是「没用不了 Buffer」，而是：常量已经在 FParameters 的隐式 UB 里；路点列是 StructuredBuffer。§4.1 要解决的是「Scene / View 给一百个 shader 共用同一份数据」，我们没有这个问题。

4.2 为什么要 Static Binding

每个 shader、每个 stage（VS/PS）绑定槽都不同。Set{Graphics,Compute}PipelineState 会 作废全部绑定，每个 PSO 后都要重绑。

每 Draw 绑一遍Static Uniform Buffer
顺序Set PSO → 每 Draw 绑 VS/PS → 下一 PSO 再绑Set Static UB → Set PSO → 只 Draw
问题Mesh Draw Command 被多 pass/View 缓存，不能为每个组合生成一套绑定UB 绑在 command list 的 静态槽，shader 要时从槽里取
频率PSO / DrawPass
IMPLEMENT_STATIC_UNIFORM_BUFFER_SLOT(SceneTextures);
IMPLEMENT_STATIC_UNIFORM_BUFFER_STRUCT(FSceneTextureUniformParameters, "SceneTexturesStruct", SceneTextures);
IMPLEMENT_STATIC_UNIFORM_BUFFER_STRUCT(FMobileSceneTextureUniformParameters, "MobileSceneTextures", SceneTextures);

同一槽同时只能绑一个。尽量复用槽。RHICmdList.SetStaticUniformBuffers 设置；RDG 在每个 pass 执行前自动绑。静态 UB 应出现在 pass 的 parameter struct 里。

5. FRDGBuilder：建图与 Execute

官方：实例化 FRDGBuilder → 建资源、加 pass → FRDGBuilder::Execute 编译并执行。Builder 建在栈上，析构前必须 Execute。图 API 单线程，同一时刻只能有一个实例（不能嵌套、不能并排）。Deferred / Mobile 每次场景渲染共用一张大图。

步API此时 GPU？
1FRDGBuilder GraphBuilder(RHICmdList)否
2CreateTexture / CreateBuffer只分配 Descriptor，RHI 显存在 Execute 才分配
3AddPass(名字, 参数, Flags, lambda)否，只登记
4参数必须用 AllocParameters，填上本 lambda 会用到的 RDG 资源否；RDG 用这些推依赖和 Transient 寿命
5Execute()这时才 Compile + Draw
AddPass 参数含义
RDG_EVENT_NAME("MyShader %d", …)profiler 名，printf 语义
Pass parameter struct带 RDG 资源的扩展 shader 参数
ERDGPassFlags::Compute / Raster / Copy / AsyncCompute这个 pass 允许哪种命令
lambdaExecute 时往 command list 录工作；可能并行

Compute 用 FRHIComputeCommandList（和 Async 共用接口）。Raster 用 FRHICommandList。避免 FRHICommandListImmediate，否则该 pass 不能并行。理想 lambda 无副作用；若必须在 Render Thread 上创建/锁 RHI，才用 immediate。

FRDGBuilder GraphBuilder(RHICmdList);
FMyShaderCS::FParameters* PassParameters = GraphBuilder.AllocParameters<FMyShaderCS::FParameters>();
PassParameters->SceneColorTexture = SceneColor;
PassParameters->SceneColorOutput = GraphBuilder.CreateUAV(NewSceneColor);

GraphBuilder.AddPass(
    RDG_EVENT_NAME("MyShader %d%d", View.ViewRect.Width(), View.ViewRect.Height()),
    PassParameters,
    ERDGPassFlags::Compute,
    [PassParameters, ComputeShader, GroupCount](FRHIComputeCommandList& RHICmdList)
    {
        FComputeShaderUtils::Dispatch(RHICmdList, ComputeShader, PassParameters, GroupCount);
    });

GraphBuilder.Execute();

时间线做什么不要做什么

8. RDG 资源与 Views

RDG 资源一开始只有 Descriptor。底层 RHI 只在 声明了该资源的 pass 的 lambda 里才能 GetRHI()。Setup 里调用会 assert。指针归 Builder，析构后全部作废。

种类怎么创建寿命
TransientCreateTexture / CreateBuffer锁在图内；不相交可 alias
ExternalRegisterExternal{Texture,Buffer} 或 Extract伸出图外
ViewAPI给 shader
SRVCreateSRV只读
UAVCreateUAVCS / 部分光栅可写
FRDGTexture* Texture = GraphBuilder.CreateTexture(FRDGTextureDesc::Create2D(...), TEXT("MyTexture"));
// 非法: Texture->GetRHI();
FRDGTextureUAV* TextureUAV = GraphBuilder.CreateUAV(FRDGTextureUAVDesc(Texture, MipLevel));
FRDGBuffer* Buffer = GraphBuilder.CreateBuffer(FRDGBufferDesc::CreateBufferDesc(...), TEXT("MyBuffer"));
FRDGBufferSRV* BufferSRV = GraphBuilder.CreateSRV(Buffer, PF_R32_FLOAT);

9. Pass 与 Parameters（三种写法）

参数必须 AllocParameters，保证寿命。RDG 有自己的宏；AddPass 只消费 RDG 宏，普通 shader 宏给 SetShaderParameters。官方故意让 pass 参数和 shader 参数同一套 API，减少样板。

9.1 只有 shader、没有 RDG（基线）

HLSLC++ 宏
Texture2D MyTextureSHADER_PARAMETER_TEXTURE(Texture2D, MyTexture) → FRHITexture*
RWTexture2D MyUAVSHADER_PARAMETER_UAV → FRHIUnorderedAccessView*
float MyFloatSHADER_PARAMETER(float, MyFloat)

栈上 FParameters，立刻 SetShaderParameters + Dispatch。IMPLEMENT_GLOBAL_SHADER(..., "MainCS", SF_Compute)。

9.2 Shader + RDG pass

改成效果
SHADER_PARAMETER_RDG_TEXTURE读 FRDGTexture*，RDG 记读边
SHADER_PARAMETER_RDG_TEXTURE_SRV读 SRV
SHADER_PARAMETER_RDG_TEXTURE_UAV写 UAV
仍用 SHADER_PARAMETER(float)RDG 忽略，只给 SetShaderParameters
可以赋 nullptrRDG 忽略空字段

ERDGPassFlags::Compute 表示这个 pass 只能 发 Compute 命令。lambda 里再 SetComputeShader + SetShaderParameters(*PassParameters)，非空 RDG 字段此时已解成 RHI。

9.3 没有 shader 的 pass（Copy）

BEGIN_SHADER_PARAMETER_STRUCT(FCopyTextureParameters, )
    RDG_TEXTURE_ACCESS(Input,  ERHIAccess::CopySrc)
    RDG_TEXTURE_ACCESS(Output, ERHIAccess::CopyDest)
END_SHADER_PARAMETER_STRUCT()

用于「pass 和 shader 不是一对一」或根本没有 shader。Flags 用 ERDGPassFlags::Copy。lambda 里 RHICmdList.CopyTexture(Input->GetRHI(), Output->GetRHI(), …) —— 这里 GetRHI() 合法。

10. Raster Pass 与 Load Action

固定管线 RT 用 RENDER_TARGET_BINDING_SLOTS()。RHI 用 render pass 绑 RT；RDG 自动 Begin/End，你只提供绑定。Tile GPU 上 Load Action 必须准确才有性能。

ERenderTargetLoadAction含义
ELoad保留旧内容
EClear清成 optimized clear
ENoAction不保证旧内容；整屏都会写时部分硬件更快

Depth/Stencil 要分别指定 load，并用 FExclusiveDepthStencil 控制读写。官方例子：Color 用 ENoAction + lambda 里 DrawClearQuad；DepthStencil 用 EClear + 空 lambda（清由 action 完成）。

UAV 光栅（不绑传统 RT）：FPixelShaderUtils::AddUAVPass，自己指定 viewport。

11. 依赖、Cull、Mip 链

资源出现在 AddPass 的 struct 上，就可能延长寿命或与更早 pass 连边。尽量只声明真正用到的；不用的设 null。

难点：shader permutation 可能编掉某个资源。用 ClearUnusedGraphResources(*ComputeShader, PassParameters) 把 shader 没用到的 RDG 字段清掉。多 shader 版本：只有「所有 shader 都不用」才清。

图 3 · 依赖边来自参数字段，不是手画箭头。Mip 链 = 对每一级重复：读上一级 SRV，写下一级 UAV 或 RT。

官方用 FGenerateMips 演示：Raster 走 AddFullscreenPass + RenderTargets[0] = FRenderTargetBinding(Texture, ELoad, MipLevel)；Compute 走 FComputeShaderUtils::AddPass + MipInSRV / MipOutUAV。

13. External 与 Transient

13.1 External：寿命伸出图外

方式API寿命伸到指针何时有效
登记进去RegisterExternal{Texture,Buffer}图 开头Setup 立刻有 RDG 句柄（底层已是 pooled IPooledRenderTarget / FRDGPooledBuffer）
从图里取出QueueTextureExtraction图 末尾Execute 之后 才填好
立刻转 ExternalConvertToExternal{Texture,Buffer}图开头（立刻分配）Setup；不能再和本帧其他资源 alias

图 A extract → 图 B register，用同一套 pooled 类型即可往返。图外若不再持有引用，仍可能和本帧更早/更晚的 RDG 资源共享池内存。

ConvertToExternal 用在「等不到 Execute 结束就必须拿资源」。和 Extract 的最大差别是寿命方向：Convert 伸到图头，Extract 伸到图尾。

13.2 Transient

Compile 时规划执行轴上的分配，寿命不相交可以重叠。有 Transient allocator 的平台，峰值显存通常低于「按 RHI Descriptor 匹配资源池」。

点说明
开关r.RDG.TransientAllocator
查 alias bug关掉它对比
不要假设资源里有上一帧合法内容。Alias 后是垃圾。资源池常掩盖这类问题

图 5 · 官方 Transient：A 用完后同一块内存可以给 C。不要读「清之前」的内容。

14. RDG Uniform Buffer 与 Upload

14.1 RDG Uniform Buffer

UB 里可以装 RDG 资源。Setup 只建 Descriptor，Execute 才建 RHI UB。确认没用则 Cull，永不初始化。

API作用
CreateUniformBuffer(参数 struct)创建 RDG UB
SHADER_PARAMETER_RDG_UNIFORM_BUFFER必须写在交给 AddPass 的 struct 上，lambda 里才能解引用
AddPass会扫 子 UB，不只扫根参数

当前限制：RDG UB 不能 靠 shader 反射把不用的资源裁掉。要手剪，或为每套参数建不同 UB。实践见 Deferred 的 Scene Textures UB。

14.2 QueueBufferUpload

图执行前要把 CPU 数据灌进 Buffer：用 QueueBufferUpload。RDG 在 Compile 时批处理，并可和其他 Compile 任务重叠。

规则原因
要用 RDG 做 uploadpass 里 Lock/Unlock immediate list = 同步点，破坏并行
Upload 的 Buffer 自动非 TransientTransient 不支持 CPU upload
选准 ERDGInitialDataFlags数据能活过 deferral 用 NoCopy，否则让 RDG 拷一份

16. 调试、Validation、Insights

RDG 是 延迟结构。崩在 Execute / RHI 线程时，调用栈离 Setup 很远。RHI 线程开着时，正在执行的命令离 Setup 又远一层。

16.1 Immediate Mode

绕过 Compile，在 AddPass 里立刻跑该 pass。lambda 空指针时，调试器能直接看到 Setup。

方式值
CVarr.RDG.ImmediateMode
命令行-rdgimmediate
